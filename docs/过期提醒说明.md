# 过期提醒（微信推送）

当某个账号的免扫凭证**超过 20 小时没有续期**时，通过微信推一条提醒，避免一路拖到过期才弹码。

只提醒，不自动处理。续期仍按 `docs/保活选项说明.md` 的规则执行。

---

## 1. 支持的渠道

| 渠道 | 需要填 | 说明 |
|------|--------|------|
| **PushPlus**（推荐） | token | <https://www.pushplus.plus> 微信扫码登录，复制 token。免费额度够用 |
| **Server酱** | SendKey | <https://sct.ftqq.com> 微信登录取 SendKey |
| **Bark** | key 或完整地址 | iOS 用；填 key 即可，也支持 `https://api.day.app/xxx` |
| **自定义 Webhook** | 完整 URL | POST JSON：`{"title":"…","content":"…","text":"…"}` |

前两个都推到微信，配置最简单。

---

## 2. 配置

### 界面

主界面右侧 → 选中任意沙箱 → **过期提醒（微信推送）**：

1. 勾选「凭证超时未续期时推送提醒」
2. 选渠道（默认 PushPlus）
3. 粘贴 token / SendKey
4. 「超过 20 小时提醒，同一账号 6 小时内不重复」——按需要改
5. 点 **保存**，再点 **发送测试** 确认能收到

「立即检查」会马上扫一遍所有沙箱并推送（用于验证或手动排查）。

### 配置文件

程序目录 `notify.json`：

```json
{
  "enabled": true,
  "channel": "pushplus",
  "token": "你的token",
  "warnHours": 20,
  "repeatHours": 6
}
```

`channel` 取值：`pushplus` / `serverchan` / `bark` / `webhook`。

---

## 3. 命令行

```text
JskpBoxManager.exe notify             扫描一遍，有超期就推送
JskpBoxManager.exe notify --test      发一条测试消息
JskpBoxManager.exe notify --check     同 notify
```

配合 `--appdir 目录` 可指定含 `profiles` 的安装目录。

退出码：`0` 正常（含「没有超期」）、`1` 发现超期但推送失败、`2` 未配置。

---

## 4. 什么时候会自动检查

| 时机 | 说明 |
|------|------|
| 每次保活跑完 | `refresh` 结束后顺手扫一遍全局 |
| 界面开着时 | 每 10 分钟检查一次 |
| 手动 | 界面「立即检查」或命令行 `notify` |

---

## 5. 判定规则

- 「凭证年龄」取 **live 与金库中较新那个** `tdi_account.txt` 的写入时间，所以刚扫码不会被误判。
- 超过 `warnHours`（默认 20 小时）才算超期。
- 同一把 key 在 `repeatHours`（默认 6 小时）内只提醒一次；**换了新 key 或已续期，记录自动清除**，下次超期能立刻再提醒。
- 凭证无效（未登录 / 已标需要扫码）的账号不提醒——那类问题在界面「登录」列已经标红。

状态文件：`logs\notify-state.json`。

---

## 6. 推送内容长什么样

```text
向僵管家：3 个账号超过 20 小时没有续期

以下账号的免扫凭证已超过 20 小时没有换新，有掉线/弹码风险：

· qb3（黑皇奥德彪）：25.3 小时，已停止
· qb8（小叄相见恨晚）：23.1 小时，游戏中
· qb2（简单）：21.4 小时，已停止

请打开管家确认：如果是游戏一直开着，关掉游戏就会自动续期；
如果已停箱，可以直接点「⚡ 纯协议续期」。
```

---

## 7. 排障

| 现象 | 处理 |
|------|------|
| 测试收不到 | 检查 token 是否复制完整；PushPlus 关注公众号了吗；Server酱的 SendKey 是否失效 |
| `code=903 用户令牌不正确` | token 填错或已重置，重新复制 |
| `code=400` 之类 | 多为当日免费额度用完，换 Server酱或明天再试 |
| 命令行说「没有超期」但界面显示很久没续 | 界面看的是「免扫链」天数；提醒看的是**这把 key 的写入时间**，两者不同 |
| 想临时关掉 | 取消勾选「凭证超时未续期时推送提醒」并保存，或把 `enabled` 改 false |
