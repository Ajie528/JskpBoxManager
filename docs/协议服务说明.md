# 协议服务说明

把「扫码固化的免扫会话」暴露成本机 HTTP 接口，脚本用环境变量注入地址，向本游戏取 `wx.login` code，再拿 code 去换业务 Token。

对齐参考仓库 [YYB-Go-Enhanced](https://github.com/525815266/YYB-Go-Enhanced) 的用法，但实现路径不同：

| 步骤 | 本程序做法 |
|------|------------|
| 1. 固化高权限 Session | 每个沙箱扫码后，ilink `AutoAuthKey` 进金库（原有能力） |
| 2. SERVER 不写死 IP | 脚本读 `JSKP_SERVER` / `YYB_SERVER` |
| 3. 调 `/wxapp/*` 并带 APPID | `POST /wxapp/getCode`，仅允许本游戏 `wx31a9c726536cdacc` |
| 4. 获取授权凭证 | 用 CDP 在沙箱内真实运行时调用 `wx.login` |
| 5. 换业务 Token | **脚本侧**调用游戏自己的后端；本程序不代登第三方业务 |

不走原生 ilink 协议仿真（见 `docs/mmtls直连可行性研究.md`）。

要摸清「code 之后打哪个游戏登录接口」，用 `capture` / `unpack`，见 `docs/抓登录接口与解包.md`。

---

## 启用

1. 打开管理界面，勾选顶部 **协议服务**。
2. 点 **复制令牌**，得到 Bearer Token。
3. 状态栏 / 旁边会显示 `http://127.0.0.1:18000`。

也可用命令行（不打开界面）：

```text
JskpBoxManager.exe server
JskpBoxManager.exe server --port 18000
```

配置写在程序目录 `protocol.json`（令牌、端口；固定只监听 `127.0.0.1`）。

---

## 脚本环境变量

```text
set JSKP_SERVER=http://127.0.0.1:18000
set JSKP_PROTOCOL_TOKEN=你的令牌
set JSKP_REF=qb1
```

兼容参考仓库写法（每行一个账号）：

```text
set YYB_SERVER=http://127.0.0.1:18000@qb1
set YYB_PROTOCOL_TOKEN=你的令牌
```

示例脚本：`scripts/get_wx_code.py`。

## 接口

鉴权：请求头 `Authorization: Bearer <令牌>`（也可用查询参数 `?token=`）。

### `GET /health`

健康检查，无需令牌。

### `GET /accounts`

列出沙箱、uin、是否需要扫码、游戏是否在跑。

### `GET /token?ref=qb1`（推荐，实测可用）

跑「抓包 + keylog 冷启动免扫登录 + 解密」一条龙，返回业务 token。耗时约 2 分钟、会冷启动该箱、需本机装 Wireshark（含 Npcap）。

```bash
curl -H "Authorization: Bearer <令牌>" "http://127.0.0.1:18000/token?ref=qb1"
```

返回：

```json
{"ok":true,"appid":"1048","wx_appid":"wx31a9c726536cdacc","js_code":"...","token":"...","uin":"...","open_id":"...","box":"qb1"}
```

可选 `&seconds=130`。失败返回 502 + `error`。

> `/wxapp/getCode`（下面）走 CDP，对本游戏取不到码（WeChatAppEx 无调试口），保留仅为兼容；取凭证请用 `/token`。

### `POST /wxapp/getCode`（本游戏不可用）

```json
{
  "ref": "qb1",
  "app_id": "wx31a9c726536cdacc",
  "ensure_running": true,
  "timeout": 45
}
```

- `ref`：`qb1` / `1` / 该号的 ilink uin  
- `app_id`：必须是本游戏 APPID，其它一律拒绝  
- `ensure_running`：游戏没开时尝试拉起（默认 true）

成功：

```json
{
  "ok": true,
  "code": "081xxxxx",
  "box": "qb1",
  "app_id": "wx31a9c726536cdacc",
  "uin": "...",
  "via": "cdp:9301"
}
```

失败一般为 HTTP 502，`error` 字段说明原因（要扫码、无凭证、调试页没有 `wx.login` 等）。

命令行直接取码（不经 HTTP）：

```text
JskpBoxManager.exe getcode qb1
```

## 前置条件

1. 目标沙箱已经扫过码，免扫凭证有效。  
2. 取码时小游戏最好已在跑；否则会尝试打开游戏中心。  
3. QQ 浏览器需带 `--remote-debugging-port`（本程序启动时已加）。若 WeChatAppEx 自带调试口，也会一并尝试。

若返回「未找到可执行 wx.login 的页面」，多半是小程序 JS 上下文没挂到可调试 Target：先确认游戏窗已开，再试；仍不行需要针对当前 WMPF 版本继续排查 CDP Target。

---

## 安全

- 默认只绑 `127.0.0.1`，不要改成局域网监听。  
- 令牌等同登录权：不要提交 `protocol.json`，不要发给别人。  
- `wx.login` code 短时一次性，拿到后立刻换业务 Token，不要日志落盘明文长期存。
